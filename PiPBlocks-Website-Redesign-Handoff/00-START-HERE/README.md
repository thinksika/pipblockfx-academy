# PiP Blocks Website Redesign Handoff Pack

This pack is for Antigravity / Claude Code. Start with `00-START-HERE/MASTER_BUILD_PROMPT.md`.

## What is included

- **01-PRIMARY-DESIGN-SCREENS** — preferred PiP Blocks desktop/mobile concepts inspired by the CoffieFX page flow. These are the main UI references.
- **02-SUPPORTING-DESIGN-EXPLORATIONS** — additional/older screen concepts. Use them only for ideas; do not mix conflicting designs.
- **03-COFFIEFX-REFERENCE-SCREENSHOTS** — screenshots supplied by the user of CoffieFX's mobile UI/menu/footer.
- **04-REAL-PIPBLOCKS-BRAND-ASSETS** — actual PiP Blocks logo, mark and event photos, including four new event/panel photographs.

## Important image instruction

Screen designs are layout references. Some concept screenshots contain placeholder/generated photographic content. **Do not use people or photographs from the design mockups in the website.** Use only the real photos and logo in section 04 and any additional authentic assets verified on pipblockfx.com / the current repository.

## Recommended order

1. Read the master prompt.
2. Inspect the current PiP Blocks website and repository.
3. Review primary screens first.
4. Use supporting screens only if they add a useful idea.
5. Build, test and push to the existing PiP Blocks repository on a safe review branch.

No source code or production website is modified by this reference pack itself.
